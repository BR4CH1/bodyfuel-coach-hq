# BodyFuel Coach

Baue mir eine moderne Web-App für mein Online-Coaching „BodyFuel“.

Stil:

Dark Mode, sportlich, hochwertig, schwarz/gold, ähnlich Fitness-App. Name: BODYFUEL Nutrition Coaching.

Funktionen:

1. Login-Seite für Kunden

2. Kunden-Dashboard

3. Tagescheck mit Checkboxen:

- Eiweißziel erreicht = 3 Punkte

- Trinkziel erreicht = 2 Punkte

- 3 Portionen Obst/Gemüse = 2 Punkte

- Schrittziel erreicht = 2 Punkte

- Training absolviert = 3 Punkte

- 7+ Stunden Schlaf = 2 Punkte

- Recovery gemacht = 1 Punkt

4. Punkte sollen automatisch zusammengerechnet werden.

Maximal 15 Punkte pro Tag.

5. Level-System:

- Rookie: 0–99 Punkte

- Grinder: 100–249 Punkte

- Athlete: 250–499 Punkte

- Elite: 500–799 Punkte

- Beast: 800–1199 Punkte

- Legend: 1200+ Punkte

6. Dashboard anzeigen:

- aktuelles Level

- Gesamtpunkte

- Streak

- Fortschrittsbalken zum nächsten Level

- heutige Punkte

- Wochenpunkte

- nächste Check-in Erinnerung

7. Fortschrittsbereich:

- Gewicht eintragen

- Bauchumfang eintragen

- Fortschrittsfotos hochladen

- Verlauf als Grafik anzeigen

8. Ernährungsplan-Bereich:

- PDF hochladen und anzeigen

- aktueller Plan

- Archiv alter Pläne

9. Coach-Dashboard:

- Übersicht aller Kunden

- Level, Punkte, Streak, letzter Check-in

- Warnhinweise, wenn jemand 3 Tage nichts eingetragen hat

- Kunden anklicken und Details sehen

10. Erfolge/Achievements:

- Protein King: 30 Tage Eiweißziel erreicht

- Hydration Hero: 30 Tage Trinkziel erreicht

- Iron Athlete: 50 Trainings abgeschlossen

- On Fire: 14 Tage Streak

- Legend Status: 1200 Punkte erreicht

Bitte baue zunächst einen schönen klickbaren Prototypen mit Dummy-Daten für Stefan, Michelle und Mia. Wichtig: Es soll mobil gut aussehen, aber auch am Desktop wie ein professionelles Dashboard wirken.
